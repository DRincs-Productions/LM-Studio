# Recommended Review Skills

| Name | Description | Intended for | Install command |
|---|---|---|---|
| [Story Skills](https://github.com/danjdewhurst/story-skills) | Narrative critique, scene craft, line editing and continuity review. | Codex and Gemini CLI: shared Agent Skills; Gemini uses them only as review guidance. | `npx skills@latest add danjdewhurst/story-skills --skill '*' --agent codex -g -y` |
| [Image Skills](https://github.com/simota/image-skills) | Image brief, prompt and report-only image review workflow. | Codex and Gemini CLI: shared Agent Skills. Adapt review to our `sd-cli` outputs; verify Gemini image input in an evaluation. | `npx skills@latest add simota/image-skills --skill '*' --agent codex -g -y` |
| [AKOÚŌ](https://github.com/sonicfieldlabs/akouo) | Listening rubrics separating signal evidence, interpretation and uncertainty; includes music, speech and audiovisual modes. | Codex and Gemini CLI: shared portable `SKILL.md` instructions. Confirm Gemini audio-file support in an evaluation. | `npx skills@latest add sonicfieldlabs/akouo --skill '*' --agent codex -g -y` |
| [Earshot](https://github.com/Leonxlnx/earshot) | Audio analysis and comparison tools plus agent listening skills. | Codex Coordinator only if its CLI/MCP integration is adopted. Gemini must not receive MCP tools. | **Python package:** `python -m pip install 'git+https://github.com/Leonxlnx/earshot.git'`<br>**Agent Skills:** `npx skills@latest add Leonxlnx/earshot --skill '*' --agent codex -g -y` |
| [Google Agents CLI Eval](https://github.com/google/agents-cli/tree/main/skills/google-agents-cli-eval) | Evaluation harness and multimodal custom-metric guidance; not a production reviewer. | Codex: optional evaluation reference for matched Gemini/reviewer comparisons. The framework targets Google Agents CLI. | `npx skills@latest add google/agents-cli --skill google-agents-cli-eval --agent codex -g -y` |

The `skills` CLI currently detects Codex on this machine and installs into the shared `~/.agents/skills` directory. Gemini CLI also discovers that directory, so a separate `--agent gemini-cli` install is unnecessary here. Gemini is an experimental reviewer candidate. Codex on the server owns MCP tools, artifact handoffs, deterministic assertions and final decisions. Installing a skill does not establish reviewer quality or approve it for production.
