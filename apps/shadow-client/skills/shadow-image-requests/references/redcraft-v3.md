# RedCraft v3.0 (Krea2)

Use this guide for the `nsfw` profile and checkpoint `redcraft_redmix_hybrid` (`redcraftREDMIXHybridA2A_30Krea2.safetensors`). The author page covers many versions. The selected release is Civitai version 3139241. It lists Euler, Simple, CFG 1, and 8–12 steps; Shadow Image Worker uses 12 steps. RedCraft 3.0 FixQW21T is a separate Qwen-Image 2.1 checkpoint.

Write a compact English visual description in this order when applicable:

1. State the subject count and visually important traits, clothing, pose, and interaction.
2. State framing, point of view, and where subjects or props sit in the frame.
3. Specify the setting, direction and quality of light, materials, and preferred photographic or cinematic finish.
4. For a cutout, preserve the complete subject and any held prop, leave margin around the silhouette, and allow the server to add its solid-background instruction.

This structure is project guidance. The supplied release description gives rendering presets and does not prescribe a prompt grammar or mandatory trigger tokens. At CFG 1, specify critical visual requirements positively in the main prompt.

Example: “Waist-up photographic portrait of one adult ceramicist in a slate-blue work shirt, seated in profile at a studio window. A copper watering can rests on the near edge of the bench, fully visible. Soft late-afternoon light from the left, warm clay and muted charcoal tones, shallow depth of field.”
