# Handoff 07 — Animated visual assets and 2D rigs

**Status:** Future exploration. No tool, runtime, production workflow, or integration has been selected or implemented.

## Goal

Explore whether the project should support creating and using animated visual assets for narrative scenes, characters, and other generated content. Candidate tools may include Spine/Spine2D and similar 2D rigging or animation applications. Keep the exploration open to other suitable tools.

## Questions for a later evaluation

- What kinds of animation are needed: character movement, facial expressions, layered portraits, scene effects, or other narrative visuals?
- What source assets and authoring steps are required, and which steps could be automated safely?
- Which export formats, runtimes, licenses, and target platforms are supported by each candidate?
- How would an exported animation be previewed, validated, stored, versioned, and shown by the intended narrative client?
- What are the costs, hardware needs, and practical limits of producing and rendering these assets?
- How should generated or externally authored assets be reviewed for visual quality and consistency?

## Deferred task

Evaluate Spine/Spine2D and suitable alternatives, then decide what authoring workflow, export formats, and runtime integration to use. This remains future work; no tool or implementation approach has been selected.

## Scope and constraints

Do not assume Spine is the preferred option or that a usable MCP integration, command-line interface, or game runtime is available. Verify current product capabilities and licensing before making a recommendation. Compare Spine/Spine2D with relevant alternatives using a small, representative proof of concept before selecting a workflow.

This handoff records an area to explore later. It does not authorize installing paid software, purchasing a license, changing the existing image-generation pipeline, or committing to a runtime or asset format. Record the evaluation and proposed workflow here before implementation begins.
